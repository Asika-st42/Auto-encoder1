# TPC Autoencoder Project

This project uses Autoencoders and TPC hit data for cluster extraction and anomaly detection.

## Files

- `notebooks/`: example notebooks
- `data/`: TPC hit CSV data
- `src/`: Python scripts
- `results/`: generated figures and outputs

## Current tasks

1. Run the example notebooks.
2. Visualize TPC hits in 3D.
3. Plot hits in selected TPC layers.
4. Extract local maxima in phi-time images.
5. Save 5x5 or 7x7 cluster images for Autoencoder training.
